## 版本号规则

- 格式：`major.minor.patch`（如 `1.0.10`）
- Android VersionCode = major × 10000 + minor × 100 + patch
- 示例：`1.0.10` → `10010`

## 发版顺序

**必须先发 Android，再发 WebAPI！**

原因：Android 发版脚本会更新 WebAPI 的 `appsettings.json`（AppUpdate.Releases 配置）。
